# Inji Interoperability Playground

MOSIP Decode 2026 submission — a visual playground for issuing, holding,
presenting, and verifying Verifiable Credentials across Inji Certify, Inji
Wallet/Web, and Inji Verify, proving real interoperability (not just internal
compatibility) with standards-compliant implementations outside Inji too.

## Team

4-person team. Roles roughly split as: issuer & backend, wallet, verifier &
protocol, playground UI & docs. See each component's own README as it lands.

## Status

Early build. Components land here as they're built and tested.
